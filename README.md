# 全国リアルタイム地震ビューア V15

V15では端末の加速度センサー（DeviceMotion）を地震検出に使用しません。日本全国の地震情報・緊急地震速報・全国感知情報を受信し、揺れを検出した地域を表示・日本語で読み上げます。

## 地図UI

地図はLeafletと同梱したNatural Earthの海岸線・国境データを使い、参考画像に合わせた暗色の全国地図にしています。強震モニタのリアルタイム震度／最大加速度の画像色、地震の震源、発表震度、速報、P/S到達予測を同じ地図に表示します。白い別地図はありません。Leafletを読み込めない場合は簡易地図となり、ライブ画像色の地理座標への重ね合わせは行いません。

陸上の丸は、防災科研の[公開観測点リスト](https://www.kyoshin.bosai.go.jp/ja/stationlist/)にあるK-NET・KiK-netの位置を使用します。2026-10-06取得時点で休止と表示されている地点を除き、陸上1,728地点と海上6地点を同梱しています。北海道から沖縄・離島まで47都道府県に分布します。

海底は[防災科研の海底観測点情報](https://www.seafloor.bosai.go.jp/st_info/)の2026-10-07時点の設置座標243地点（S-net 150、DONET1 22、DONET2 29、N-net 36、相模湾6）を使用します。S2N13は公開一覧のS2N13Aを使用します。合計1,977地点です。海底の青い輪と陸上の灰色点は未受信を示し、平常状態や稼働状態を意味しません。観測点のツールチップに観測網・コード・受信時刻を表示します。

初期表示は全国が収まるよう、地図の大きさに合わせて縮尺を設定します。観測点の位置データは `js/stations.js` と `js/seafloor-stations.js` に同梱しているため、表示のたびに防災科研へ問い合わせません。

P波/S波は受信した震源情報と発生時刻からの概算到達予測です。一定速度P=6km/s、S=3.5km/sの簡易表示で、気象庁の走時表による正確な到達時刻ではありません。requestAnimationFrameで滑らかに描画し、毎フレームの実時刻から半径を計算するため、背景タブから戻っても時刻に追いつきます。10分で終了し、新しい震源では古い描画ループを解除します。波形からP/Sを判定するものではありません。

## 地図データ

Google Maps APIは使用しません。地図背景はNatural Earthの公開ドメインデータを同梱しており、APIキー不要です。詳細測量用の地図ではありません。出典・ライセンス・変換元URLは `THIRD_PARTY_NOTICES.md` と `data/` 内に記録しています。

## データ

- P2P地震情報 v2 WebSocket: 気象庁地震情報、緊急地震速報（警報）、地震感知情報など
- 気象庁: 震源・震度情報の公開JSONを60秒ごとに確認。観測点の緯度・経度と震度を使い、発表された観測震度を色付きの丸で表示します。
- DMDATA WebSocketは使用していません。
- 防災科研の強震モニタ: 利用者から一般公開を含む取得・配信の許可取得済みとの申告を受け、「リアルタイム震度」「最大加速度」の公式画像を中継経由で表示します。ローカル版は同梱の中継、Pages版はCloudflare WorkersのHTTPS中継を使用します。画像の色を数値へ変換したり、別の観測網に値を割り当てたりしません。公開・再配信は取得した許可の範囲内で行ってください。

「揺れを観測した地域」は気象庁の発表をもとに都道府県・最大震度・地点数・時刻を表示します。白枠の大きい点は気象庁の観測震度、細かい色付き点は強震モニタ画像の色です。座標が含まれない情報を近くの観測点や地域の中心へ推測で割り当てません。同じ発表のP2P情報で座標を消したり、古い発表で最新の点を上書きしたりしません。

**数値の毎秒取得は未対応です。** 強震モニタ画像の色を、観測点IDと座標が一致する地点へ表示します。画像上のピクセル対応はMITライセンスのコミュニティ資料で、公式APIの保証ではありません。移設後の座標差・対応不明・同じピクセルを共有する地点は除外します。画像のサイズ変更はエラーにし、透明・白黒のピクセルを観測値として扱いません。色を震度／Gal値に逆算したり、色から地震を検出・通知したりしません。S-net等へ陸上の色を流用しません。正確な数値表示には許可済みの観測点ID・計測値・時刻の配信仕様が必要です。

## 強震モニタと時刻

全国地図の上部で「リアルタイム震度」「最大加速度」を切り替えます。観測点の色と公式スケールだけが変わり、地図・震源・速報・拡大位置は維持されます。右の欄は地震情報・速報・観測地域専用です。スマートフォンでも同じ統合地図を表示します。

「リアルタイム震度」「最大加速度」を選ぶと、地表の公式画像を1秒ごとに確認します。前の取得が終わるまでは次の取得を開始せず、非表示のタブでは取得を休止します。同じ観測時刻の画像は再読込しません。観測時刻をJSTで表示し、遅延や取得失敗は状態欄に表示します。画像の更新失敗時は最後の画像を残すため、必ず観測時刻も確認してください。

更新は時計・観測点の色・観測時刻・状態欄だけを書き換え、全体の自動リロードはしません。色が変わった地点だけスタイルを更新し、地図・音声コントローラーは作り直しません。取得失敗時は最後の色と観測時刻を残してエラーを表示します。指標の切り替え時には古い指標の色を消し、受信前に誤表示しません。

画面上部の現在時刻は端末の時計を使い、日本標準時（JST）で1秒ごとに更新します。観測時刻・地震の発生時刻とは別です。ブラウザが休止中の場合、更新は再表示時に追いつきます。端末の時計がずれている場合は現在時刻もずれます。

[強震モニタの説明・利用条件](https://www.kyoshin.bosai.go.jp/ja/about_kmoni/)にあるように、リアルタイム震度は通常の観測震度と同じではなく、地震以外の振動が表示される場合もあります。このアプリを避難判断の唯一の情報源にはしないでください。

## 緊急地震速報と警報音

警報音は初期状態でOFFです。「警報音」または「警報音テスト」を利用者が操作して音声再生を有効にすると、新しく受信した速報で独自の警報を再生します。鋭い音色で780 Hzから1480 Hzへ上昇する3連音を3回、約2.6秒間鳴らします。各音の立ち上がりと終わりに短いフェードを入れ、音の間と各組の間に休止を設けています。ゲインの上限は旧警報の0.16を超えない0.14とし、音量の引き上げではなく音色・音程・リズムを変更しています。ただし、同じゲインでも音色やスピーカーによって聞こえる大きさは異なります。公式の緊急地震速報チャイムを使用したものではありません。同一報の重複・過去履歴・訓練・取消は鳴らさず、予報から警報への更新や最大震度上昇は再通知します。取消時とOFF時は再生を停止します。ブラウザの再生制限、消音、スピーカーの状態によって実際には聞こえないことがあるため、最初にテストしてください。

右の情報欄には受信した予報・警報・報数・最終報・取消、予測地域の震度を表示します。震度1は青、2は緑、3は黄、4はオレンジで、5弱以上も段階別に色分けします。震度不明は灰色です。PLUMの識別情報がある地域は「PLUM」と表示し、到達時刻やP/Sリングを推測で補いません。このアプリが独自にPLUM法を計算する機能ではありません。

[P2Pの配信仕様](https://www.p2pquake.net/develop/json_api_v2/)ではコード556は警報で、予報と最終報フラグの配信は保証されません。予報・最終報の表示は明示的な受信フィールドにのみ反応し、時刻や報数だけで最終報を作りません。これらの表示はローカルの模擬データでテストでき、実配信へ接続するには対応する許可済みデータ源が別途必要です。

## 読み上げ

ブラウザの Web Speech API を使用します。ページを開いた直後はOFFで、「読み上げ OFF」を押すと開始確認の音声を再生し、以後に受信した地震情報を自動で読み上げます。ページを再読み込みしたときは再度ONにしてください。「読み上げの声」でブラウザが利用できる日本語音声を選択できます。声の選択はこのブラウザのローカルストレージに保存し、次回も使います（保存が制限されている場合は今回のみ）。声の変更だけでは音声を鳴らさず、現在の読み上げを中断せず次の文から反映します。「自動選択」は従来どおり端末の日本語音声を優先します。保存した声が一時的に利用できない間は自動選択で読み上げを継続し、声が戻ったら選択を復元します。選べる声は端末・ブラウザによって異なり、オンライン音声には接続が必要な場合があります。

「音声テスト」で再生を確認でき、最新地震の「読み上げ」で表示中の震源・最大震度・規模・深さ・観測地域を再生できます。震度1・2の地震も対象です。起動時や再接続時の過去の履歴は自動では読み上げません。緊急地震速報は通常の読み上げに優先します。音声が使用できない場合は画面に理由を表示します。

## 小さい揺れ

受信した震度1・2の地震情報も表示・通知・読み上げの対象です。P2P地震情報の利用者による「揺れた」報告は「揺れの報告」に地域名・件数・時刻を表示し、地域の代表位置に水色の丸を表示します。公式の[地域コード定義](https://p2pquake.github.io/epsp-specifications/epsp-specifications.html#base-6)を使用し、位置が不明な報告には地図マーカーを作りません。報告の読み上げは同じ地域で1分に1回までです。

利用者の報告は震度未確定として表示し、気象庁の観測震度と区別します。このアプリは公開された情報を受信するもので、震度1未満の微振動を波形から独自に検出する機能はありません。

## 開発

このPCでは `start-preview.cmd` を実行すると、同梱済みのCodex用Node.jsでビルドし、5175番のプレビューを起動できます。インストール・キー発行は行いません。サーバーの画面は利用中開いたままにしてください。別のPCではNode.js 22以降を用意し、以下のコマンドを使用します。

Node.jsで `node scripts/serve.mjs` を実行し、`http://127.0.0.1:5173/` を開きます。別ポートを使う場合は `node scripts/serve.mjs 5174` と指定します。サーバーはローカルPCからの接続のみ受け付けます。

Node.js 22以降で `node --test tests/*.test.mjs` を実行します。`tests/browser.html` は模擬地震・感知報告・観測震度・速報の予報/警報/最終報/取消をローカルの画面にだけ注入する受信テストです。外部へ報告を送信しません。気象庁のテスト用JSONは[2026-10-07の公開報告](https://www.jma.go.jp/bosai/quake/data/20261007160547_20261007160305_VXSE5k_1.json)から必要なフィールドを抜粋しています。

P波/S波リングをローカルで確認する場合は、URL末尾に `?demo=1` を付けるとテスト用震源を表示します。

## GitHub Pages

APIキーや独自のシークレットは不要です。公開先のリポジトリ名が変わっても、HTML、ESモジュール、manifest、Service Workerは相対パスで動作します。

1. このプロジェクトの内容をリポジトリのルートに配置します。隠しフォルダ `.github/workflows/pages.yml` も含めてください。
2. GitHubの **Settings > Pages > Build and deployment > Source** を **GitHub Actions** にします。
3. デフォルトブランチへ反映するか、Actionsの **Deploy QuakeWatch to GitHub Pages** を手動実行します。

ワークフローはテスト後に `node scripts/build.mjs` を実行し、必要な22ファイルだけの `dist/` を公開します。テスト、開発スクリプト、設定の生成物、環境ファイルは公開用ビルドへ含めません。標準のGitHub Pagesデプロイ権限を使用し、APIキーを発行しません。[GitHubの公式手順](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)も参照できます。

**GitHub Pagesだけでは強震モニタの中継サーバーを実行できません。** `workers/strong-motion.mjs` をCloudflare Workersの `quakewatch-v15-relay` として公開し、Pagesのオリジン `https://nekokun148.github.io` からのCORSを許可しています。取得先は防災科研の時刻JSONと既知のGIF画像に固定し、任意のURL、他サイトからのブラウザ利用、リダイレクト、異常画像を拒否します。画像は改変しません。現在の取得元までの通信はHTTPのため、この部分をHTTPSだと説明しません。

Pagesワークフローのビルド時だけ、公開設定 `KMONI_API_BASE=https://quakewatch-v15-relay.kouryou148.workers.dev/api/strong-motion/` をHTMLのbodyへ設定します。APIキーやトークンは使用しません。通常のローカルビルドは従来の同じPCの中継を使います。別の中継へ変更する場合は、この公開URLとWorkerのCORS許可オリジンを合わせてください。

Workers無料プランにはアカウント全体で1日100,000リクエストの上限があり、UTCの午前0時にリセットされます。毎秒の時刻確認と新しい画像の取得で、表示中の端末ごとに最大約2リクエスト/秒を使います。複数人の長時間利用や、上流サービス・回線・ブラウザの停止も含め、常時動作や速報到達は保証できません。キャッシュ・同時取得の集約・非表示タブの休止で無駄な取得を抑えますが、この上限をなくすものではありません。[Cloudflareの制限](https://developers.cloudflare.com/workers/platform/limits/)を参照してください。有料プランへの変更は別途利用者が判断してください。

ローカルで公開先と同じサブディレクトリ構成を確認する場合は、`node scripts/build.mjs` の後に `node scripts/serve.mjs 5175 --pages` を実行し、`http://127.0.0.1:5175/quakewatch-v15/` を開きます。PWAは同じプロジェクトの静的ファイルと背景地図だけをキャッシュし、外部の最新地震APIと強震モニタのAPI・観測画像はキャッシュしません。完全オフラインではライブ地震情報の取得はできません。

J-SHISの `https://www.j-shis.bosai.go.jp/map/api/postfix` と `labs/api/postfix` はURLの形式例です。postfixを[公式API一覧](https://www.j-shis.bosai.go.jp/api-list)にあるサービスのパスへ置き換えます。提供されるハザード・地盤情報は現在の揺れではないため、このアプリの毎秒観測値の取得先には使用しません。

公開先リポジトリは [Nekokun148/quakewatch-v15](https://github.com/Nekokun148/quakewatch-v15)、Pagesの共有先は [全国リアルタイム地震ビューア V15](https://nekokun148.github.io/quakewatch-v15/) です。実際の公開状態はActionsのデプロイ結果と公開画面で確認してください。

## 現在地

初期設定はONで、起動時にブラウザの位置情報取得を試みます。初回はブラウザの許可が必要です。OSの位置情報設定やブラウザの許可を強制的に変更することはできません。拒否・未対応・取得失敗は状態欄に表示します。「現在地 OFF」にすると取得を停止し、マーカーを消し、次回もOFFにします。「現在地 ON」に戻すと再開します。

現在地はピンクの点と精度範囲で表示し、全国表示の縮尺は変えません。位置の履歴や座標は保存せず、地震情報サービスへ送信しません。位置情報は地震・微振動の検出には使用しません。
