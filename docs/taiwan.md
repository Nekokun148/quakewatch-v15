# 台湾の地震情報（利用者による許可制）

## 受信する情報

台湾の中央氣象署（CWA）が公開する警報・特報RSSのうち、地震の見出しと公式ページへのリンクを別欄に表示します。公式RSSの原文の見出しを変更せず、出典を明示します。RSSに載らない地震は含みません。掲載0件は「台湾で地震が発生していない」という意味ではありません。

これは地震発生後の情報への入口です。台湾の緊急地震速報（EEW）、台湾の全地震、リアルタイム観測震度を受信する機能ではありません。見出しから震度・震源座標・規模・深さを抽出してデータ化したり、台湾と日本の震度階級を換算したりしません。地図の震源・日本の最新地震・履歴・P/S到達予測・自動警報音・読み上げには流しません。

## 利用者の操作

1. サイドバーの「台湾の地震情報」を開きます。
2. 「台湾情報の受信を許可」にチェックを入れた場合だけ、RSS取得を開始します。
3. やめる場合はチェックを外します。進行中の取得も中断し、見出しを消去します。

初期状態はOFFです。許可は保存しないため、再読み込みやページを開き直した後は再度ONにします。ブラウザの戻る操作でページが復元された場合もOFFに戻します。DMDATAのキー、台湾用のキー、位置情報、通知権限は使いません。ON操作によって中継サーバーへ接続し、必要な場合に中継サーバーがCWAへRSSを取りに行きます。利用者のキーや現在地は送りません。

## 通信と制限

- 通常は60秒ごと。非表示タブでは取得を休止します。OFFでは通信しません。
- 失敗時は60秒から最大15分へ待機を延ばします。429のRetry-Afterがそれ以上なら、その待機時間を尊重します。
- APIの不在・アクセス拒否は受信停止として表示し、自動で別の配信元へ乗り換えません。
- 取得先は固定の公式HTTPS RSSだけです。任意URL、リダイレクト、HTML、DTD・外部実体宣言、262144バイトを超える応答は拒否します。
- 中継は同時取得をまとめ、成功・失敗とも最低60秒は上流アクセスを抑えます。公式側の長い待機指示にも従います。Workerではエッジキャッシュを利用します。
- ページのService WorkerはRSSやAPI応答をキャッシュしません。中継の共有キャッシュはRSSのみを対象にし、キーや個人設定を保存しません。

## ローカル版

更新後の scripts/serve.mjs は、ページと同じサーバーに api/strong-motion/taiwan を提供します。すでに旧サーバーが起動している場合は、利用者自身が既存の Start-QuakeWatch.cmd の窓を終了してから起動し直す必要があります。二重起動しないでください。エージェントは既存の利用者サーバーやDMDATA接続を勝手に終了しません。

## GitHub Pages版

ブラウザから公式RSSへの直接接続はCORSを確認できなかったため使いません。既存の強震モニタ中継の workers/strong-motion.mjs に、固定の台湾RSS経路を追加しています。許可オリジンは既存の https://nekokun148.github.io のままです。

公開には、更新したWorker（workers/taiwan-rss.mjsを含む）と公開用Pagesの両方の反映が必要です。Pages用の既存KMONI_API_BASEから同じ中継のtaiwan経路を選びます。Workerが未更新なら未対応として受信を止めます。ソースやビルドの成功は、公開済み・実受信成功を意味しません。

## RSSの利用条件

この実装は個人・非商業のRSS見出し閲覧を対象とします。公式の利用条件に合わせ、原文の見出しとリンク、出典だけを表示します。RSSを加工した震度分布・警報・予測などの派生情報は作成しません。商業利用や別用途への拡張には、別のデータ利用条件の確認が必要です。

- [中央氣象署 RSSサービスと利用条件](https://www.cwa.gov.tw/V8/C/S/eservice/rss.html)
- [公式の警報・特報RSS](https://www.cwa.gov.tw/rss/Data/cwa_warning.xml)
- [中央氣象署の地震情報](https://www.cwa.gov.tw/V8/C/E/index.html)

## 検証の区別

tests/taiwan.test.mjs は模擬API、模擬XML文書構造、模擬タイマーで検証します。tests/taiwan-permission-20261016/ はブラウザ標準XMLパーサーと実際のチェック操作を確認するローカル専用ページで、表示見出しは模擬データです。どちらも実際の台湾地震ではなく、公開ビルドには含めません。実RSSを取得した場合も、地震の実掲載がなければ受信経路の確認と実地震の表示確認を分けて報告します。
